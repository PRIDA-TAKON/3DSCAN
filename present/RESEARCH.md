# งานวิจัยและหลักการทางเทคนิค: 3D Gaussian Splatting (3DGS)

## 1. บทนำ (Introduction)
3D Gaussian Splatting เป็นเทคนิคการเรนเดอร์ภาพแบบ Neural Rendering ที่เปิดตัวในปี 2023 โดยมีเป้าหมายเพื่อแก้ปัญหาความช้าของการเรนเดอร์ในเทคนิคเดิมอย่าง NeRF (Neural Radiance Fields) โดยเปลี่ยนจากการใช้ Neural Network มาเป็นการใช้ "3D Gaussians" หรือกลุ่มก้อนอนุภาคทรงรีที่มีความโปร่งแสงมาเรียงต่อกันจนเกิดเป็นภาพ

## 2. หลักการทำงานสำคัญ (Core Principles)

### 2.1 การแทนค่าฉากด้วย 3D Gaussians
ฉาก 3 มิติจะถูกประกอบขึ้นจาก Gaussians นับล้านจุด โดยแต่ละจุดประกอบด้วยพารามิเตอร์:
*   **Position (μ):** ตำแหน่งจุดกึ่งกลาง (X, Y, Z)
*   **Covariance (Σ):** กำหนดรูปร่าง ขนาด และทิศทาง (Scale & Rotation) โดยใช้สมการ $Σ = RSS^TR^T$
*   **Opacity (α):** ค่าความโปร่งแสง (0-1)
*   **Spherical Harmonics (SH):** ข้อมูลสีที่เปลี่ยนไปตามมุมมอง (View-dependent color) ทำให้เห็นแสงสะท้อนที่สมจริง

### 2.2 Tile-Based Rasterization (หัวใจของความเร็ว)
กระบวนการเรนเดอร์ไม่ได้ใช้วิธี Ray Tracing ที่ช้า แต่ใช้การ "สาด" (Splatting) จุดลงบนหน้าจอ:
1.  **Tiling:** แบ่งหน้าจอเป็นช่องเล็กๆ (Tiles) ขนาด 16x16 พิกเซล
2.  **Sorting:** เรียงลำดับ Gaussians ตามระยะความลึก (Depth) เฉพาะในแต่ละ Tile
3.  **Alpha Blending:** คำนวณสีของแต่ละพิกเซลโดยรวมค่าสีและความโปร่งแสงของ Gaussians ที่ซ้อนทับกัน

### 2.3 Optimization & Adaptive Density Control
ระบบจะเริ่มต้นจากจุดพิกัดที่ได้จาก **Structure-from-Motion (SfM)** เช่น COLMAP จากนั้นจะใช้ Gradient Descent ปรับพารามิเตอร์ของทุกจุด และมีกลไกพิเศษ:
*   **Densification:** เพิ่มจุดในบริเวณที่มีรายละเอียดสูงหรือมีจุดน้อยเกินไป
*   **Pruning:** ลบจุดที่แทบจะมองไม่เห็น (โปร่งแสงเกินไป) ทิ้งเพื่อประหยัดทรัพยากร

## 3. ความโดดเด่นของ Taichi Implementation (ในโปรเจคนี้)
โปรเจคนี้เลือกใช้ `taichi_3d_gaussian_splatting` ซึ่งมีจุดแข็งเหนือกว่าตัวต้นฉบับ (Official CUDA):
*   **Higher Efficiency:** สามารถให้คุณภาพภาพ (PSNR) ที่ดีกว่า โดยใช้จำนวนจุดเพียง **20-25%** ของต้นฉบับ (เช่น ข้อมูลชุด Truck ใช้จุดเพียง 4 แสนจุด เทียบกับต้นฉบับที่ใช้ 2 ล้านจุด)
*   **Maintainability:** เขียนด้วยภาษา Taichi (Python-based) ทำให้การปรับแต่งโค้ดทำได้รวดเร็วกว่า C++/CUDA
*   **Scalability:** รองรับการทำงานบน Cloud ได้อย่างราบรื่นผ่าน PyTorch Integration

## 4. โครงสร้างระบบบน Cloud (System Architecture)
โปรเจคนี้ไม่ได้รันเพียงแค่บนเครื่อง Local แต่ถูกออกแบบให้เป็น **Production-ready Cloud Native App**:
*   **Google Cloud Run (Serverless GPU):** ใช้ทรัพยากร GPU L4 (24GB VRAM) ซึ่งเป็นเทคโนโลยีใหม่ล่าสุดที่เหมาะสมที่สุดสำหรับงาน AI Inference และ Training เนื่องจากประหยัดไฟแต่มีประสิทธิภาพสูง
*   **Worker-based Architecture:** แยกส่วน Frontend (Next.js) และ Worker (Python) ออกจากกันชัดเจน เชื่อมต่อด้วย Supabase (Database) ทำให้ระบบเสถียรและสามารถ Scale ออกได้ตามต้องการ
*   **Pay-per-use Model:** การใช้ Cloud Run Jobs ทำให้ไม่ต้องเสียค่าเช่า GPU รายเดือน แต่เสียเงินเป็นวินาทีเฉพาะตอนที่มีคนอัปโหลดวิดีโอเข้ามาจริงเท่านั้น

## 5. การเปรียบเทียบ: 3D Gaussian Splatting vs. LiDAR Point Cloud
ในอุตสาหกรรมการสแกน 3 มิติ มักมีการเปรียบเทียบระหว่างเทคนิคที่ใช้ภาพ (3DGS) กับเทคนิคที่ใช้เลเซอร์ (LiDAR) ดังนี้:

### 5.1 ด้านความสมจริง (Visual Fidelity)
*   **LiDAR:** ผลลัพธ์เป็น "จุด" (Points) ที่ลอยอยู่ในอวกาศ แม้จะมีสีแต่ภาพที่ได้จะดูไม่อิ่มตัว มีช่องว่างระหว่างจุด (Holes) และไม่สามารถเก็บรายละเอียดของแสงสะท้อนหรือความเงาของวัตถุได้
*   **3DGS:** ผลลัพธ์เป็น "Gaussians" ที่มีความโปร่งแสงและซ้อนทับกัน ทำให้ภาพที่เรนเดอร์ออกมาดูเป็นเนื้อเดียวกันเหมือนภาพถ่ายจริง (Photorealistic) และด้วยเทคนิค **Spherical Harmonics** ทำให้ 3DGS สามารถจำลองแสงสะท้อน (Specular Reflection) บนพื้นผิวโลหะหรือแก้วได้สมจริงกว่า LiDAR อย่างมาก

### 5.2 ด้านอุปกรณ์และการเข้าถึง (Accessibility)
*   **LiDAR:** ต้องใช้อุปกรณ์เฉพาะทางที่มีราคาแพง เช่น เครื่องสแกนเลเซอร์ 3D หรือ iPhone รุ่น Pro/iPad Pro เท่านั้น
*   **3DGS:** ใช้เพียง **วิดีโอจากกล้องธรรมดา** (Smartphone ทั่วไป) ก็สามารถสร้างโมเดลคุณภาพสูงได้ ทำให้กลุ่มผู้ใช้งานกว้างกว่าและต้นทุนการผลิตคอนเทนต์ต่ำกว่า

### 5.3 ด้านการนำไปใช้งาน (Use Cases)
*   **LiDAR:** เหมาะกับงานที่ต้องการความแม่นยำเชิงวิศวกรรม (Engineering Precision) เช่น การวัดระยะโครงสร้างตึก
*   **3DGS:** เหมาะกับงานที่ต้องการความสวยงามและความสมจริง (Visual Experience) เช่น E-commerce, Gaming, VR/AR, และการสร้าง Digital Twin ของโบราณวัตถุหรือสถานที่ท่องเที่ยว

## 6. สรุปความได้เปรียบเชิงเทคนิค
| คุณสมบัติ | LiDAR Point Cloud | 3D Gaussian Splatting | 3DGS (Taichi Cloud) |
| :--- | :--- | :--- | :--- |
| **ความสมจริง** | ต่ำ (ดูเป็นจุดๆ) | สูงมาก (เหมือนภาพถ่าย) | **สูงมาก + แสงสะท้อนสมจริง** |
| **ความแม่นยำมิติ** | สูงมาก (ระดับมม.) | สูง (ระดับซม.) | สูง (เพียงพอสำหรับงาน Visual) |
| **การเข้าถึง** | ต่ำ (ต้องมี LiDAR) | สูง (ใช้มือถืออะไรก็ได้) | **สูงสุด (อัปโหลดผ่านเว็บ)** |
| **ความเร็วเรนเดอร์** | เร็ว (ขึ้นอยู่กับจำนวนจุด) | เร็วมาก (Real-time) | **เร็วมาก (100+ FPS)** |
| **ขนาดไฟล์** | ใหญ่มาก | ใหญ่ | **Optimized (เล็กลง 75%)** |
