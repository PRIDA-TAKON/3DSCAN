3DScan Cloud

The Future of 3D Reconstruction

High-Fidelity 3D Models from Any Video

Powered by Google Cloud GPU L4 & Taichi 3DGS

The Problem

  • ความต้องการคอนเทนต์ 3D สูงขึ้น (E-commerce, AR/VR)
  • การสแกนแบบเดิม ใช้อุปกรณ์แพง (LiDAR) หรือประมวลผลช้ามาก
  • ซอฟต์แวร์ใช้งานยากและต้องมีเครื่องแรง

Our Solution

"3DScan Cloud Platform"

  • อัปโหลดวิดีโอผ่าน Web Browser ได้ทันที
  • ประมวลผลบน Cloud GPU แรงสูง (L4)
  • ได้ไฟล์ 3D ที่สมจริงระดับภาพถ่าย (Photorealistic)

Core Technology

3D Gaussian Splatting

  • เรนเดอร์เร็วกว่า NeRF ถึง 100 เท่า
  • ใช้พารามิเตอร์ 3D Gaussians ล้านจุด
  • เก็บแสงสะท้อน (Specular) ได้สมจริง

Taichi Implementation

  • ใช้จุดน้อยลง 75% แต่ชัดเท่าเดิม
  • ประหยัด Bandwidth และ Storage
  • รันบนระบบ Serverless Cloud Run

3DGS vs. LiDAR Point Cloud

คุณสมบัติ LiDAR Point Cloud 3DGS (ของเรา)
ความสมจริง (Fidelity) ต่ำ (เห็นเป็นจุดแยกกัน) สูงมาก (เหมือนภาพถ่าย)
แสงสะท้อน / โลหะ ทำไม่ได้ ทำได้สมจริงมาก
อุปกรณ์ (Hardware) ต้องมีเซนเซอร์ LiDAR (แพง) มือถือธรรมดาอะไรก็ได้
การเข้าถึง (Access) จำกัดรุ่นเครื่อง ทุกคนที่มีกล้องวิดีโอ

Production-Ready Architecture

  • Google Cloud Run GPU: รันเมื่อมีงาน ไม่เสียค่าเช่ารายเดือน
  • GPU L4 (24GB VRAM): ประมวลผล AI รุ่นล่าสุด
  • One-Pot Execution: ทุกขั้นตอนจบใน Pipeline เดียว
